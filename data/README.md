# TRACE demo data

This is a realistic synthetic temporal dataset designed for the hackathon demo. Synthetic data is used because the demo needs product decisions, releases and outcomes that are not present in ordinary public review datasets.

The key scenario is `checkout-mobile`, which demonstrates:

- first detection
- product decision
- product change
- measured outcome
- later redesign
- recurrence

This makes it possible to demonstrate why long-term memory is materially different from a one-shot feedback summary.
